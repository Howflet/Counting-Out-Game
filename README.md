# Counting-Out-Game
## Description

The Counting Out Game is a Python-based game that utilizes a circular linked list to simulate the process of elimination among players. The game is built using Tkinter for the graphical user interface (GUI). Players enter two values: N (Number of players) and K (Safe position)

The game randomly eliminates players until only one remains, who is declared the winner.
Features:

- Graphical Interface (Tkinter) for user interaction
- Circular Linked List Implementation for managing players
- Randomized Elimination Process to determine the last remaining player
- Dynamic UI Updates to reflect eliminations in real-time

## Requirements

- Python 3.x
- Tkinter (built into standard Python distributions)

## How to Run

Ensure you have Python installed.

Run the script:

    python Counting Out Game.py

Enter values for N (total players) and K (safe position).
Click Start to initialize the game.
Click Eliminate to begin eliminating players.
The game continues until one player remains.

## Game Rules

The number of players (N) must be between 2 and 11.
The safe position (K) must be ≥ 1.
Players are eliminated randomly until only one remains.
